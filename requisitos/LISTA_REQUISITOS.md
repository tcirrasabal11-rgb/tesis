# Información necesaria para continuar la tesis

El paquete permite avanzar en revisión y borradores mientras se reúnen estas entradas. Cada pendiente debe enlazar al archivo o decisión que lo resuelve.

| Entrada | Quién la confirma | Decisión que permite cerrar |
|---|---|---|
| Guía, rúbrica y plantilla de la universidad | Usuario y universidad | Orden de capítulos, formato y bibliografía. |
| Asesor, línea y observaciones | Usuario y asesor | Requisitos del plan y entregables. |
| Inicio/fin, coordenadas, longitud y ancho | Reconocimiento de campo | Ámbito y número viable de unidades. |
| Tipo de pavimento y homogeneidad | Inspección técnica | Procedimiento PCI aplicable. |
| Norma PCI completa y edición | Acceso legítimo y especialista | Medición, curvas y cálculo documentado. |
| Bibliografía primaria | Investigación de fuentes | Antecedentes y base de métodos. |
| Componentes y condiciones del drenaje | Campo y especialista | Indicadores aplicables y no aplicables. |
| Escala y protocolo validados | Metodología, expertos y asesor | Puntuación e instrumentos de campo. |
| Mapa de emparejamiento y dependencia | Metodología y estadística | Análisis y límites de inferencia. |
| Fichas, medidas y evidencia real | Equipo de campo | Resultados propios. |
| Plan y decisiones analíticas revisados | Estadística y asesor | Inferencia defendible. |
| Revisión académica y visual final | Revisor, usuario y asesor | Entrega de versión final. |

Las plantillas no completan estas entradas con suposiciones. Al formular una consulta explica qué decisión depende de su respuesta y qué trabajo puede seguir mientras tanto.
